# 竞品市场决策台 Demo V2.0

一个用于业务评审的自包含交互 Demo，演示从竞品市场事实、竞对诊断、机会识别、策略判断到执行复盘的完整链路。

## 使用

直接打开 `index.html`，或通过 GitHub Pages 访问。

## 说明

- 页面数据为合成演示数据，不代表真实经营结果。
- “销量”指购买热度文案的区间下限代理值，不是订单实销量。
- “市场份额”指监控样本内的销量代理值份额，不代表 Amazon 完整类目市场份额。
- Demo 不包含真实接口、内部数据或业务凭证。

## 页面

- 市场总览
- 竞对诊断
- 机会中心
- 策略工作台
- 执行复盘

## 技术

原生 HTML、CSS、JavaScript 和 SVG；不依赖构建工具、后端服务或第三方 CDN。
